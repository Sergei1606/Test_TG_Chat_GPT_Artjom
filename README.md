# Telegram ChatGPT Bot 🤖
Многофункциональный Telegram-бот с интеграцией ChatGPT, 
диалогами с историческими личностями, квизами и другими возможностями.

## 🌟 Возможности

- **ChatGPT**: Общение с ИИ в реальном времени
- **Диалоги с личностями**: Общайтесь с Эйнштейном, Шекспиром и другими
- **Квизы**: Тесты по программированию, истории и науке
- **Рандомные факты**: Интересные научные факты
- **Переводчик**: Многоязычный перевод текстов
- **Помощник по резюме**: Генерация профессиональных резюме

После запуска бота используйте команды:

Команда	Описание
/start	Главное меню
/gpt	Чат с ChatGPT
/quiz	Начать квиз
/random	Случайный факт
/translate	Переводчик текста
/resume	Помощник по резюме
Или выбирайте функции через интерактивные кнопки:


🌍 Переводчик
Выберите язык перевода

Отправьте текст
Получите перевод с возможностью смены языка

Пример:

text
Выберите язык: Английский 🇬🇧
Текст: Привет, как дела?
Перевод: Hello, how are you?

📄 Помощник по резюме
Бот пошагово запросит:

Ваше ФИО
Образование
Опыт работы
Навыки

И сгенерирует профессиональное резюме в формате: text
