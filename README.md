# Telegram ChatGPT Bot 🤖

Многофункциональный Telegram-бот с интеграцией ChatGPT, диалогами с историческими личностями, интерактивными квизами и другими продвинутыми возможностями. Разработан с учетом отказоустойчивости и современных асинхронных паттернов.

## 🌟 Возможности

- 🤖 **ChatGPT**: Общение с ИИ в реальном времени.
- 👥 **Диалоги с личностями**: Общайтесь с выдающимися людьми (Эйнштейн, Шекспир и др.) в их неповторимом стиле.
- 🧠 **Квизы**: Тесты по программированию, истории, науке, географии и кино с проверкой ответов и объяснениями от ChatGPT. Отслеживание счета в реальном времени.
- 🎲 **Рандомные факты**: Генерация интересных малоизвестных научных фактов.
- 🌍 **Переводчик**: Интеллектуальный многоязычный перевод текстов с сохранением исходного форматирования.
- 📄 **Помощник по резюме**: Пошаговая генерация профессионального структурированного резюме по предоставленным данным.

## 🚀 Команды бота

Команда | Описание
--- | ---
`/start` | Главное меню с интерактивными кнопками
`/gpt` | Чат с ChatGPT
`/talk` | Диалог с известной личностью
`/quiz` | Начать квиз на выбранную тему
`/random` | Получить случайный факт
`/translate` | Запуск переводчика
`/resume` | Интерактивный помощник по резюме

*Все функции также доступны через удобное интерактивное меню кнопок в самом чате.*

## ⚙️ Технологии

- Python 3.10+
- `python-telegram-bot` (Telegram Bot API v20+) — Полная асинхронность и использование `ConversationHandler`.
- `openai` — Официальный асинхронный клиент OpenAI API (`AsyncOpenAI`).
- `python-dotenv` — Безопасное хранение ключей в переменных окружения.
- `poetry` / `pip` — Управление зависимостями (присутствует как `pyproject.toml`, так и `requirements.txt`).

## 🛠 Установка и запуск

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Sergei1606/Test_TG_Chat_GPT_Artjom.git
   cd Test_TG_Chat_GPT_Artjom
   ```

2. Настройте ключи доступа:
   Создайте файл `.env` в корневой директории проекта и добавьте в него токены:
   ```env
   TG_BOT_TOKEN=ваш_токен_telegram_бота
   CHATGPT_TOKEN=ваш_токен_openai
   ```

3. Установите зависимости:
   **С использованием Poetry (рекомендуется):**
   ```bash
   poetry install
   ```
   **С использованием стандартного pip:**
   ```bash
   pip install -r requirements.txt
   ```

4. Запустите бота:
   ```bash
   python main.py
   ```

## 📝 Особенности реализации

- Использованы современные методы `async`/`await` как для общения с серверами Telegram, так и для API OpenAI (за счет чего бот не блокируется при обработке долгих ответов от ChatGPT).
- Реализована надежная структура переходов и кнопок "Закончить" (работающих аналогично команде `/start`) внутри `ConversationHandler`.
- Код следует стандартам PEP-8 и является отказоустойчивым (интегрирован обработчик ошибок через `logging`).
